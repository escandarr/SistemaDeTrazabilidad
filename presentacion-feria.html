El problema

Hoy todo se gestiona en papel

  • Los materiales se calculan a mano: errores y sobrepedido
  • El pesaje y la tara se restan en una hoja
  • Cada guía se vuelve a tipear en Avesoft
  • Nadie sabe el consumo real por obra
  • Los quiebres de stock llegan sin aviso
  • Las sustituciones entre proveedores se hacen a ojo
  • No hay control de quién hace cada operación
  • Cero trazabilidad: si algo falla, no hay registro
La solución

Una app que digitaliza el ciclo completo

Cada material queda registrado y pesado, el stock se actualiza solo y el consumo real se calcula al cerrar la obra.

Caso 1 · Demostración principal

Del pedido al consumo real

Antes: el papel pierde la trazabilidad y nunca cierra cuánto se gastó de verdad en la obra.
  1. Nueva solicitud: obra Jumbo La Reina, sistema MMA, 12 m² +10%.
  2. El sistema calcula la cubicación automática (kg por material).
  3. Picking: pesa por bulto; resta la tara del proveedor y muestra bruto / tara / neto.
  4. Despacho: descuenta el stock y genera el CSV para Avesoft.
  5. Devolución: pesa lo que volvió y reingresa al inventario.
  6. Cierre con el consumo real de la obra.
El momento clave

Consumo real = Despachado − Devuelto, con la trazabilidad completa: solicitud → picking → despacho → devolución.

Caso 2

Quiebre de stock y equivalente

Antes: se acaba un material y hay que llamar al proveedor o adivinar el reemplazo.
  1. Inventario muestra RESI56 en rojo: bajo el mínimo.
  2. La alerta también aparece en el Inicio.
  3. En el picking, cuando el stock no alcanza, el sistema ofrece el equivalente de otro proveedor (RESI56R) con su stock.
  4. Un botón “Usar equivalente” hace el cambio.
El momento clave

La alerta salta sola y el reemplazo ya está sugerido. Cero improvisación, cero obra detenida.

Caso 3

Alta del equipo, y segura

Antes: sin control de acceso; cualquiera podía hacer cualquier operación.
  1. Usuarios → Nuevo: se genera un enlace de invitación.
  2. El usuario abre el link y crea su propia contraseña, con medidor de seguridad en vivo.
  3. Carga masiva por CSV para dar de alta a todo el equipo de una vez.
  4. Cada rol ve solo lo que le corresponde.
El momento clave

Invitación por enlace + contraseñas de alta entropía + permisos por rol. Onboarding en segundos y con control.

Caso 4 · Para el jurado técnico

Integración con Avesoft, sin API

El reto: Avesoft no expone API; todo se tipeaba a mano, dos veces.
  1. Materiales → Importar el maestro de productos por CSV.
  2. Exportar el catálogo y el inventario cuando se necesite.
  3. El despacho genera el CSV de salidas por centro de costo.
  4. La devolución genera el CSV de reingreso.
El momento clave

Conectamos ambos mundos por archivo, que es como Avesoft trabaja de verdad. Sin doble digitación.

Cómo está construido

Arquitectura

Frontend · PWA

React + TypeScript. Instalable, funciona en la bodega desde el celular.

Backend · API

FastAPI (Python) con control de acceso por rol y la lógica de pesaje y consumo.

Datos

PostgreSQL. Cada operación queda registrada y trazable.
